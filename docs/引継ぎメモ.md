## 起動・テストの方法

1. [Node.js](https://nodejs.org/)をインストール
2. アプリのフォルダで`起動.bat`をダブルクリック（Windows）、または`node server.js`を実行
3. ブラウザで`http://localhost:3100`を開く（ポートは環境変数`PORT`で変更可能）

テストを実行する場合:

```
npm test
```

`test/server.test.js`にあるテストが実行されます。

必要な環境変数（なくても最低限は動くが、機能によっては設定が必要）:

- `ADMIN_USERNAME` — 管理者になるユーザー名（未設定だと既定値`sakurajpau`）
- `STRIPE_SECRET_KEY` / `STRIPE_WEBHOOK_SECRET` — 課金機能に必要
- `ANTHROPIC_API_KEY` — AIおすすめ機能に必要
- `PORT` / `DB_PATH` — 任意

## 直すときの注意点（重要）

- **本の登録・編集・削除は1本のエンドポイント（`POST /api/books`）で、一覧を丸ごと置き換える方式です。** 個別のbookを追加・更新するAPIはありません。ここを変えるときは、フロント側（`saveBooks`）とサーバー側（`validateBooks`）の両方を必ず一緒に直してください。
- **入力の上限値はサーバー側（`server.js`の`BOOK_LIMITS`など）とフロント側（`index.html`の`LIMITS`）の2箇所に同じ値が書かれています。** 片方だけ変えると、赤字のエラー表示とサーバーの実際の制限がずれてしまうので、必ず両方を合わせて直してください。
- **セッションに有効期限がありません。** ログアウトするまで無期限に有効なので、修正する場合はセキュリティ影響をよく確認してください。
- **ログイン失敗のロック機能はメモリ上のみの実装です。** サーバーを再起動するとリセットされます。
- **管理者権限は、サインアップ時のユーザー名が環境変数`ADMIN_USERNAME`と一致するかどうかだけで決まります。** 本番環境で必ず設定してください（未設定だと既定値`sakurajpau`が管理者になれてしまいます）。
- **DBの変更は必ずマイグレーション（`db/migrations/`に新しい連番のSQLファイルを追加）で行ってください。** `data.db`を直接編集しないこと。
- **公開してよいページは`server.js`の`PUBLIC_PAGE`という正規表現で制限されています。** 新しいHTMLページを追加する場合はこの制限に注意してください（でないと404になります）。
- **Stripeは現在テストモードです。** 本番課金には別途、本番用のAPIキーとWebhookシークレットの設定が必要です。
- コードを直したら、`npm test`を実行してから、Documents側フォルダでコミット・pushしてください。
